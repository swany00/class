##과제5##

\(2*k \ (k=1, 2, ..., 300)\)으로 \(100 × 3\)행렬을 만들고, 각 열별로 3으로 나누었을 때 0이 되는 값들을 추출하는 R 코드를 작성하여 그 코드와 결과를 제출하시오.

  • 행렬간의 산술연산

    • 행렬 A와 B의 합(차)은 두 행렬이 같은 형태일 때 정의된다.

    • 같은 위치의 원소끼리의 합(차)로 정의된다.bold text \[\begin{eqnarray*} & A = \left(a_{ij}\right)_{i=1,\ldots,n; j=1, \ldots, p}, ~ B = \left(b_{ij}\right)_{i=1,\ldots,n;j=1,\ldots,p} & \\ & A \pm B = \left(a_{ij} \pm b_{ij}\right)_{i=1,\ldots,n;j=1,\ldots,p}& \end{eqnarray*}\]

##과제7##

행렬의 각 열에 대하여, 최소값 0과 최대값 1이 되도록 하는 R 코드를 작성하시오. \[z_{ij} = \frac{x_{ij} - m_j}{M_j - m_j}, ~ i = 1, \ldots, n; ~ j = 1, \ldots, p,\] 여기서 \(m_j\)는 열 \(j\)의 최소값이고, \(M_j\)는 열 \(j\)의 최대값이다.

# 샘플 데이터 생성
set.seed(123)
n <- 100  # 행 수
p <- 4    # 열 수
X <- matrix(rnorm(n * p), n, p)

# 최소값과 최대값 계산
m <- apply(X, 2, min)  # 각 열의 최소값
M <- apply(X, 2, max)  # 각 열의 최대값

# z_ij 계산
Z <- t(apply(X, 1, function(x) (x - m) / (M - m)))

# 결과 확인

min_Z <- apply(Z, 2, min)  # 각 열의 최소값
max_Z <- apply(Z, 2, max)  # 각 열의 최대값
